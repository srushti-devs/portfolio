Personal Portfolio Website
A responsive personal portfolio website built to showcase my journey as a B.Voc Software Development student and aspiring software developer.

This repository contains the source code for my portfolio, featuring dedicated sections for:
- About Me – My background, interests, and learning journey.
- Skills – Programming languages, tools, and technologies I'm learning.
- Projects – Personal and academic projects that demonstrate my practical skills.
- Experience – My learning experiences and development journey.
- Contact – Ways to connect with me.

Tech Stack
- HTML5 – Website structure
- CSS3 – Styling, layouts, and responsive design
- JavaScript – Interactive elements and functionality

Purpose

This portfolio is a continuous work in progress, reflecting my growth in software development. I will regularly update it with new projects, skills, certifications, and achievements as I explore new technologies and gain hands-on experience.
Built with curiosity, creativity, and a passion for learning.
